# QRON Platform Frontend

This directory contains the primary frontend application.

## Tech Stack

- **Framework**: Vite + React
- **Styling**: Tailwind CSS
- **Database Interaction**: Drizzle ORM

## Development

1. **Setup Environment**: `cp .env.example .env`
2. **Install Dependencies**: `pnpm install`
3. **Run Development Server**: `pnpm dev`
4. **Build**: `pnpm build`

See `../docs/technical-reference/` for routing and edge service details.
