## Weekly 10-minute ritual

1. Open Insights → Prompts.
2. Note which prompts ChatGPT answers without citing you.
3. For those, write one 60-word snippet from the Brand Kit + KB Public Product.
4. Put the snippet on the matching live page (manual). Do not auto-publish from AirOps.
5. Stop. That is the free-tier loop.
