## 📁 Where to put things
- **Documents**: Architectural specs, decision logs, and regulatory compliance (e.g., EU DPP).
- **Tasks**: Actionable work, bugs, research tickets, and operational items.
- **Reference**: Archived emails, past project notes, and long-term research.

## ⚡ Operating Cadence
- **Daily (5–10 min)**: Triage Tasks Tracker inbox → assign owner + priority + next action.
- **Weekly (30–60 min)**: Plan Sprint board from prioritized tasks; set “Top outcomes” in Mission Control.
- **Weekly (10 min)**: Archive/clean reference-only material.
