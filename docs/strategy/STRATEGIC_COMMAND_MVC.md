# Strategic Command — Minimum Viable Compliance (MVC)

**Branch:** `feature/minimal_violation_product`  
**Vertical (single focus):** Ohio Division of Cannabis Control (DCC) — **Provenance Gap**  
**Product name:** Ohio Audit Integrity Shield (OAIS)  
**Date:** 2026-08-31

## Command intent

Stop solving ten markets at once. Ship one regulated, painful vertical end-to-end:
cryptographic finality for METRC-era audit data so Ohio operators and DCC auditors
can prove provenance without manual reconciliation.

This aligns with `docs/strategy/INDUSTRY_LEADERSHIP_STRATEGY.md`: the constraint is
not more product surface — it is one believable buyer outcome.
