# AgentZ Edge Learning Scheduler (Cloudflare, no Vercel)

**Status:** isolated Cloudflare Worker for *read-only public peer feedback*, not the Python AgentZ daemon. This is the edge-compatible learning portion only.

**Execution:** a **single SQLite-backed Durable Object alarm** schedules itself every six hours, after a first `GET /health` bootstraps its initial alarm. This does **not** consume one of the account's five existing Cron Triggers; the Cloudflare Workers Free plan refused an attempted sixth trigger (error 10072). Each run makes **two unauthenticated HTTPS GET requests** to the fixed official GitHub issue comments API: AuthiChain open-agent alliances issue #2263 and Cedr Guard issue #7. It classifies author metadata but does **not** fetch or interpret comment instructions, call paid APIs, spend funds, send messages, query personal data, or change customer systems. It logs a bounded JSON summary using Cloudflare Worker observability and saves only aggregate public feedback counts and UTC timing in its **own** SQLite Durable Object. No secrets, D1, KV, queues or shared privileged AgentZ bindings.

**Routes:** `GET /health` or `GET /status` arms the single Durable Object alarm if none exists and reports the persisted last scheduled observation (or `null` if none has run). Health is not a claim that a real observation occurred. `GET /self-test` runs pure synthetic classifier fixtures with zero network. Other routes 404; writes 405. No endpoint lets a user force a GitHub network scan. A missing/failing public source is explicitly `coverage_unknown`, not zero threats or a healthy assertion.

**Security:** user/reviewer names returned by GitHub are public metadata; reports only contain counts, source aliases and next-action labels. An outside comment is *external feedback, not independent verification*. Self comments and bot accounts cannot become an independent verifier or partner. No prompt text is consumed. Upstream responses are capped to 128 KiB each and queries to 30 comments/source; older comments may not be included. No source author/role is cryptographically attested. This service performs **no model-weight training**, no autonomous outreach and **no production authorization**. It does not replace the real Python AgentZ runner / daemon.

**Tests:** `node --test workers/agentz-learning-cron/index.test.mjs`.

**Safety gates:** This Worker is deliberately independent of the existing privileged `authichain-agentz` Worker and its Durable Object. It does not change `humanHold=true` or `production_send=false`. A separate approved host/Cloudflare Container or GitLab runner is still required for the full Python AgentZ runtime, MCP transport and signed actions. Do not mistake the health route or GitHub metadata for that functionality.

**Deployment:** `wrangler deploy --config workers/agentz-learning-cron/wrangler.toml`. Cloudflare deploys the `AgentZLearningAlarm` class and automatically provisions a new isolated SQLite DO namespace. The Worker has **no Cron Trigger**. Verify deployed bindings/versions; call `/self-test`, then `/health` to arm the initial 15-second alarm. Recheck `/status` after the first alarm for an actual persisted `last_report`. A configured alarm alone is not proof a real observation ran.

**Cost:** Worker and Durable Object alarm invocations/storage count against existing Cloudflare Free allowances; exceeding limits may interrupt operations. No plan upgrade, paid infrastructure, or billing settings are authorized.
