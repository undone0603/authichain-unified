# AuthiChain Grant Narratives & Technical Specs

## 1. The Arbitrum Foundation: L2 Industrial Provenance
**Goal:** $50,000 infra grant.
**Problem:** Enterprise provenance requires 1M+ transactions/day. Ethereum L1 is too expensive; L2s lack a standardized "Industrial Truth" middleware.
**Solution:** AuthiChain is building the first L2-native 'Truth Layer' specifically for the EU Digital Product Passport (DPP). By anchoring hashes to Arbitrum One, we provide government-grade security with sub-cent transaction costs.
**Milestones:**
1. Integration of Arbitrum Nitro for batch-anchoring (Month 1).
2. Launch of the GovChain.us 'Sovereign ID' portal on Arbitrum (Month 3).
3. 500k assets verified via Arbitrum-anchored QRONs (Month 6).

## 2. Polygon CDK: The "Truth Layer" AppChain
**Goal:** $25,000 technical development grant.
**Narrative:** We are migrating our core provenance engine to a custom Polygon CDK AppChain. This allows for zero-gas verification for end-users while maintaining high-fidelity security for industrial manufacturers.
**Focus:** Visual Deterrence + Forensic Cryptography.

## 3. Ethereum Foundation: Public Goods (Anti-Counterfeit)
**Goal:** $10,000 open-source grant.
**Narrative:** Developing an open-source standard for 'Artistic Scannable Verification' (ASV). This prevents 'Phishing QRs' and protects the public from malicious redirects in physical spaces. QRON.space is the reference implementation of this Public Good.
