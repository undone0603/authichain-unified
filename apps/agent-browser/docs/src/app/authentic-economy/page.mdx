## The Trust Score

Every product that passes through the AuthiChain protocol receives a canonical trust score.

The score is a composite of:

- **Authentication signals** — cryptographic signatures, blockchain anchors, C2PA manifests
- **Freshness** — how recently the product was re-verified
- **Provenance depth** — completeness of the origin-to-consumer chain
- **Platform registration** — AuthiChain-registered products are the source of truth

Scores are HMAC-signed so any downstream system can prove the number came from AuthiChain.

→ See the [Trust Score API](/trust-score) for the full schema and verification flow.

