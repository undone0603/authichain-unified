# QRON

The [QRON public site](https://qron.space/) describes Living QR codes. Its current disclosure says this host forwards a stored scan and does not verify its signature.

A successful scan or redirect alone does not prove a signature, blockchain transaction, physical-product identity, or legal compliance. Verify each asserted property separately with identified evidence.

This documentation does not establish a public generation API contract, batch PDF endpoint, Shopify marketplace integration, points schedule, automatic webhook, counterfeit alert, or canonical trust-score service.

See [current QRON pricing](https://qron.space/pricing) rather than assuming an offer from an older document. This page authorizes no generation, purchase, form submission, webhook, outreach, or on-chain write.
