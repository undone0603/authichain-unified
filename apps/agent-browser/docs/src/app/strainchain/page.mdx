# StrainChain

StrainChain is the AuthiChain vertical for the licensed cannabis industry.

The cannabis market loses hundreds of millions of dollars annually to counterfeit products
that bypass regulatory compliance, harm consumers, and destroy brand equity.
StrainChain ends this by turning every licensed cannabis product into a verifiable truth.

## The problem

- Licensed brands like Cookies, Stiiizy, and Jeeter see their products counterfeited at scale
- Counterfeits bypass lab testing — putting dangerous products in consumers' hands
- Dispensaries have no real-time verification at point of sale
- Regulators have no visibility into where counterfeits enter the chain

## The StrainChain solution

Every licensed cannabis product gets a **cannabis QRON code** that carries:

- Brand digital signature
- State-compliant batch ID (METRC, BioTrackTHC)
- COA link from a licensed lab
- Verified THC/CBD percentages
- Blockchain-anchored chain of custody
- Hologram pairing for physical tamper evidence

One scan tells the consumer, the dispensary, and the brand: **this is real**.

## Supported regulatory frameworks

| State | Track-and-Trace | Batch format |
|-------|----------------|--------------|
| California | METRC | `1A406...` (24 chars) |
| Colorado | METRC | `1A406...` (24 chars) |
| Nevada | METRC | `1A406...` (24 chars) |

StrainChain validates batch ID format against state jurisdiction on every scan.

### Onboarding flow

1. Submit your brand's state license number
2. Connect your licensed lab's COA system
3. Generate QRON codes for your SKUs
4. Apply codes to packaging (print-and-apply or embedded hologram)
5. Go live — every scan protects your brand

## For dispensaries

### Point-of-sale verification

```
Budtender scans product QRON → Instant verdict → Allow or hold sale
```

| Verdict | Action |
|---------|--------|
| `authentic` | Allow sale, log scan event |
| `suspicious` | Hold, flag for manager review |
| `tampered` | Seize product, trigger counterfeit alert |
| `inconclusive` | Request manual COA check |

Integration available via REST API or the QRON Shopify-compatible POS widget.

## Certificate of Analysis verification

StrainChain verifies the COA before any `authentic` verdict is issued:

1. COA URL is fetched from the QRON payload
2. Lab license is cross-referenced with state registry
3. Batch number format is validated for the state
4. THC/CBD values are compared to label claim (±10% tolerance)
5. Test date is checked for regulatory validity

A COA that fails any of these checks immediately downgrades the verdict to `suspicious`.

→ See the [StrainChain skill](/skills) for agent-powered verification.

## Trust score integration

StrainChain verdicts flow into the AuthiChain [Trust Score](/trust-score) engine.
Cannabis-specific signals map directly to core trust signals:

| StrainChain evidence | Trust signal |
|---------------------|-------------|
| Brand signature valid | `signature_valid` |
| COA blockchain anchor | `blockchain_anchor` |
| Licensed lab COA | `c2pa_manifest_complete` |
| License resolved | `did_resolved` |
| Hologram present | `hologram_seal` |

The canonical score is HMAC-signed and included in every webhook payload,
giving brands and regulators a tamper-proof audit trail.
